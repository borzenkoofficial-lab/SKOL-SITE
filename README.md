# СКОЛ — сайт продукта

Промосайт настольной CRM СКОЛ для Windows.

## Запуск
```bash
npm install
npm run dev
```

## Проверка и сборка
```bash
npm run check
npm run build
npm run preview
```

## Страницы
- `/` — главная презентация продукта.
- `/tariffs` — сравнение START / PRO / BUSINESS и анимация лицензионных ключей.
- `/download` — версия, журнал изменений и переход к опубликованным релизам CRM.
- `/activation` — инструкция автономной активации.

## Перед публичным запуском
- Подключить платёжный провайдер и серверную выдачу лицензий. Сейчас сайт не принимает оплату и не выпускает ключи.
- Указать проверенные контакты поддержки.
- Опубликовать установщик в GitHub Releases репозитория CRM.
- Добавить только реальные отзывы после получения согласия клиентов.
- Утвердить цены и условия обновлений.
- Настроить политику обработки персональных данных и юридические документы.

Матрица тарифов синхронизирована с текущей схемой разрешений в CRM. Офлайн-ключ подписывается Ed25519 и привязывается к Device ID устройства.
