# СКОЛ — сайт продукта

Промосайт настольной CRM СКОЛ для Windows.

## Запуск
```bash
npm install
npm run dev
```

## Проверка и сборка
```bash
npm run check
npm run build
npm run preview
```

## Страницы
- `/` — презентация продукта и демонстрационный интерфейс.
- `/tariffs` — тарифы START / PRO / BUSINESS и форма запроса менеджеру.
- `/download` — информация о версии, журнал изменений и ссылка на релизы CRM.
- `/activation` — инструкция автономной активации.

## Источник достоверных данных о продукте

Тарифы, feature IDs, правила лицензирования, Device ID, формат токена и ограничения офлайн-модели сверяются с репозиторием CRM:
`borzenkoofficial-lab/struktura-crm-source`, ветка `fix/skol-offline-licensing-2026-10`.

Ключевой источник матрицы разрешений: `src/license-core.cjs` (объект `EDITION_FEATURES`).
Технические ограничения и пользовательский сценарий: `docs/superpowers/specs/skol-offline-license.md` и `docs/licensing/offline-license-operations.md`.

Визуальный стиль сайта — самостоятельная дизайн-система СКОЛ. Сайт Struktura не является источником интерфейсного дизайна или продуктовых данных.

## Продажа и выдача лицензий — текущий этап

- Онлайн-оплата и платёжные интеграции не используются.
- Клиент выбирает тариф и оставляет контакт через форму запроса.
- Форма пока формирует текст заявки для копирования; отправка на сервер и доставка менеджеру не реализованы.
- Менеджер согласовывает условия и получает Device ID.
- Менеджер вручную выпускает персональный ключ через License Manager и передаёт его клиенту.
- Закрытый ключ подписи не должен попадать в сайт, браузер, клиентский установщик или Git-репозиторий.

## Перед публичным запуском
- Указать подтверждённые контакты менеджера и канал отправки заявок.
- Опубликовать проверенный Windows installer в GitHub Releases CRM.
- Указать реальные цены и условия лицензирования после утверждения.
- Добавить только реальные отзывы с согласия клиентов.
- Добавить политику обработки персональных данных и юридические документы.
